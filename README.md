### Featured projects

#### [Smart Daily Planner](https://github.com/Adityaraj8118/smart-daily-planner)
Multi-user task planner with email OTP sign-up, a REST API, daily Web Push reminders and an installable PWA. Runs on SQLite locally and PostgreSQL in production. Comes with **TaskBell**, a native Android app with exact-time alarms, repeat rules and snooze actions.

`Flask` `PostgreSQL` `JavaScript` `Web Push` `Kotlin` `Jetpack Compose`

#### [AI Trading Chart Transcriber](https://github.com/Adityaraj8118/AI-Trading-Chart-Transcriber)
Reads trading chart screenshots and PowerPoint slides with the Gemini Vision API and turns 20 indicators per chart (trend, RSI, MACD, support/resistance, Bollinger Bands and more) into a formatted Excel report.

`Python` `Gemini API` `openpyxl` `pywin32`
